# Лабораторная работа: Работа со строками и массивами объектов

Учебный Maven-проект на языке Java (`org.example:UniversityTasks`), содержащий реализацию алгоритмов обработки строк, объектной модели финансовых отчётов и расчёта прогрессивного подоходного налога. Все классы и методы покрыты модульными тестами с использованием **JUnit 5**.

## Стек технологий

* **Язык:** Java 17
* **Система сборки:** Apache Maven
* **Тестирование:** JUnit Jupiter 5.11.4

## Описание реализованных заданий

### 1. Работа со строками (`StringProcessor`)

Класс содержит статические методы для обработки строк и модификации `StringBuilder`:

| Задание | Метод | Описание реализации |
| :--- | :--- | :--- |
| **1** | `stringRepeat(String string, int N)` | Возвращает строку, состоящую из `N` повторений исходной строки. При `N == 0` возвращает `""`, при `N < 0` или `string == null` выбрасывает `IllegalArgumentException`. |
| **2** | `stringFindSecondInFirst(String string1, String string2)` | Подсчитывает количество вхождений второй строки в первую (включая перекрывающиеся вхождения). При пустой или `null` второй строке выбрасывает `IllegalArgumentException`. |
| **3** | `stringNumberRenamer(String string)` | Формирует новую строку, заменяя символы `'1'`, `'2'`, `'3'` на подстроки `"один"`, `"два"`, `"три"`. |
| **4** | `stringBuilder(StringBuilder string)` | Модифицирует входной объект `StringBuilder` на месте, удаляя каждый второй по счёту символ с помощью прохода с конца строки. |
| **5\*** | `stringReverse(String string)` | Переставляет слова в строке в обратном порядке, сохраняя все пробелы (начальные, конечные и кратные между словами) строго на исходных местах. |
| **6\*** | `replaceHexToDec(String string)` | Находит в строке 8-разрядные шестнадцатеричные числа вида `0xNNNNNNNN` и заменяет их на десятичные эквиваленты с использованием `Long.parseLong(..., 16)`. |

### 2. Массивы объектов (`Payment`, `FinanceReport`, `FinanceReportProcessor`)

Модель хранения и обработки финансовых платежей:

* **`Payment` (Задание 7)** — представляет единичный платёж (ФИО плательщика, день, месяц, год и сумма в копейках типа `int`). Содержит конструкторы (включая конструктор копирования), геттеры, сеттеры, а также переопределённые методы `equals`, `hashCode` и `toString`.
* **`FinanceReport` (Задания 8–10)** — хранит массив платежей (`Payment[]`), ФИО составителя и дату создания отчёта:
    * предоставляет методы получения количества платежей и доступа к $i$-му платежу на чтение и запись;
    * формирует текстовое представление отчёта через `String.format` в методе `toString()`;
    * реализует конструктор глубокого копирования (`FinanceReport(FinanceReport other)`), при котором модификация исходного отчёта не затрагивает созданную копию.
* **`FinanceReportProcessor` (Задания 11–12\*)** — содержит статические методы фильтрации и анализа отчётов:
    * `paymentNameFinder(FinanceReport, char)` — возвращает новый отчёт с платежами людей, чья фамилия начинается на указанный символ;
    * `paymentCostFinder(FinanceReport, int)` — возвращает новый отчёт со всеми платежами меньше заданной суммы;
    * `dateFinder(FinanceReport, String)` *(12.1\*)* — вычисляет суммарный платёж на дату, переданную в формате `dd.mm.yy`;
    * `getMonthsWithNoPayments(FinanceReport, int)` *(12.2\*)* — возвращает список названий месяцев, в которых не было ни одного платежа за указанный год.

### 3. Налоговая декларация (`IncomeCertificate`, `TaxDeclaration`) — Задание 13\*

Набор неизменяемых (`final`) классов для расчёта прогрессивного подоходного налога:

* **`IncomeCertificate` (Справка о доходах)** — неизменяемый объект, принимающий в конструкторе год, ФИО гражданина, название организации и массив доходов за 12 месяцев. Инкапсуляция массива обеспечивается защитным копированием (`Arrays.copyOf`).
* **`TaxDeclaration` (Декларация о доходах)** — неизменяемый объект, принимающий год, ФИО и произвольное количество справок о доходах (`IncomeCertificate...`). Суммирует доходы по месяцам из всех источников и начисляет налог по прогрессивной шкале:
    * до `24 000` руб. с начала года — `0%`;
    * от `24 000` до `240 000` руб. — `13%` с суммы превышения порога `24 000` руб.;
    * свыше `240 000` руб. — `20%` с суммы превышения порога `240 000` руб.
